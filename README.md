# Spexbot

Spexbot är en discordbot designad för att simplifiera kommunikation mellan Styret och spexare på Discord.

## Funktioner

Discordbotten har hittils funktionalitet för att vidarebefodra privata meddelanden till en specificerad kanal på en den är med i.
Detta är menat att ge en samlad kanal för spexare att kontakta hela styret privat.

## Planerade funktioner

- Förmåga att schemalägga och skicka meddelanden till en specifik kanal.
- Förmåga att ge personer smeknamn
